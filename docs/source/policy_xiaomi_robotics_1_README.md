# Xiaomi-Robotics-1

Xiaomi-Robotics-1 (XR-1) is a Vision-Language-Action policy with a Qwen3-VL-4B backbone and a flow-matching DiT action
expert. The LeRobot integration follows the authors' open-source implementation
([XiaomiRobotics/Xiaomi-Robotics-1](https://github.com/XiaomiRobotics/Xiaomi-Robotics-1), Apache-2.0). Paper:
[arXiv:2607.15330](https://arxiv.org/abs/2607.15330). See the [complete user guide](./xiaomi_robotics_1.mdx) for
installation, checkpoint settings, training and evaluation.
